# GAME ART INSIGHT

现有网站的 GitHub Pages 产品评审版，保留页面结构、10款游戏、95条图片记录与11段真实GIF。

网页和素材按目录保存在 website-part-*.tar.gz 中，Actions核对校验值后解包发布，避免上传遗漏。素材仍保留来源、归属和待确认转载授权状态。

首页可搜索本库10款案例。未收录游戏提供 TapTap 搜索入口；GitHub Pages 不运行任意游戏即时检索服务。国内游戏榜在发布时和计划每6小时采集一次，保留实际获取时间；源站不可用时不伪装成实时排名。

发布：仓库 Settings → Pages → Source 选择 GitHub Actions。首次推送或手动运行 Publish GAME ART INSIGHT。无需配置密钥。

解包后的检查：node scripts/check-site.cjs。

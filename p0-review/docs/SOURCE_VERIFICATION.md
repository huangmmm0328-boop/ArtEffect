## 权限和成本

- 游客免费查看当前Top10已实测。https://www.momorank.com/pricing 明示历史、更多榜位和 API 另有套餐，P0未订阅。
- 页面“导出CSV 10条”可见，但两次操作未得到有效下载。不能声称该供应商CSV导出、开放API或自动更新已经连接。
- 本轮新增记录仅保存在本机内部研究预览，未公开上传榜单原始数据或 SQLite。内部人工研究范围不等于已取得专门的数据再发布授权。
- **自动采集许可、正式文件导出链路和对外再发布许可仍待确认。** automatic_sync_allowed=0。P0提供的是人工文件导入备选，不是自动榜单服务。
- 以上许可限制属于未关闭事项，提交用户验收时必须保留，不能写成“自动数据接入全部完成”。

## 后续接入条件

只有取得明确的数据使用范围和允许的免费接口／导出文档后，才为该方式增加自动适配器。遇登录、付费、缺日期、空文件、字段或口径变化时，保持异常／待核验状态，保留最后有效快照。至少积累对应真实天数后再讨论7/30/90天趋势。

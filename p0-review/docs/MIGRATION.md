# 页面迁移与阶段边界

原站和素材包原封保存在生产提交和本地备份，P0 新程序只放 p0-review/。未将 P0 发布到当前 GitHub Pages。

| 原有内容 | P0处理 | 后续阶段 |
|---|---|---|
| 市场雷达、榜单与变化 | 新独立首页、微信／抖音独立筛选、同日同榜来源、实际榜位和相邻日证据 | P1再做机会观察 |
| 游戏资料库、原10案例 | 117条素材引用和10个APP视觉身份入库保留；榜单游戏仅基础历史身份页 | P1统一档案与搜索，P2分析 |
| 用户画像 | 不复制到P0导航，不扩大旧分析 | 按任务书后续验收开发 |
| 吸量／创意研究 | P0不开发 | 后续与已有页面去重 |
| 未来预测、生成预览 | 旧站保留；P0不沿用为新预测，不新增模型或生成服务 | 后续按新任务书开发 |
| 数据来源 | 新来源权限／访问方式／同步状态及日志页 | 许可明确后逐源适配 |
| 历史 JSON | 仅审核后的真实 MomoRank 抖音文件导入 SQLite，不导入未核实日期或权限的其他来源 | 累积真实历史，不回填假数据 |

P0 实际路由：市场总览（/）、平台筛选（/?platform=wechat、douyin）、单游戏历史（/games/id）、原始行（/records/id）、来源与同步（/sources）、文件导入（/imports）、审计与备份（/audit）、只读数据接口和健康检查。

最终五大模块是后续信息架构目标，本轮不为了补齐导航而创建空功能或 P1/P2/P3 模块。待用户验收 P0 再进入下一阶段；合并、生产迁移和后端公开托管另行确认。

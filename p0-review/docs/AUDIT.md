## 部署与页面

生产是 GitHub Pages 静态网站。pages.yml 在 main 推送、每天 02:30 UTC（10:30 北京时间）及手动触发时运行：解包原素材、收集 JSON、记录变化与月报、验证、构建 site、发布 Pages。

现有一级页面是市场雷达、游戏资料库、用户画像、未来预测；另有来源页、游戏详情与 archive.html 旧站入口。现有数据和页面位于 intelligence/，构建、采集、检查程序位于 scripts/，素材打包文件由 website-archives.json 管理。

GitHub Pages 不能运行 Python 后端或持久化 SQLite。P0 在独立目录使用一个 Flask 后端、一个本地 SQLite 和一个文件同步入口；预览绑定 127.0.0.1，不暴露公网。这是验收环境，不改变生产部署。

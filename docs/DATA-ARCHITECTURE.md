当前阶段：03 / 移除竞品广告页面，重构月度美术观察与风格预览。2026-11-18。

## 边界

仅使用免费公开数据，不购买商业情报、付费API或会员历史，不要求广告账户，不引入外部付费后台。GitHub Pages承载静态页面，GitHub Actions运行每日归档流程，JSON与Git提交记录共同保存可追溯历史。来源尚未接入时显示真实状态，不用旧版TapTap榜或演示数据替代微信／抖音榜。

保留现有10款游戏、95条图片记录和11段真实GIF。素材来源、来源版本与待确认转载授权继续保留。产品素材不是广告投放证据；官方公开可看不自动等于授权转载。

## 身份、来源与时间

`gameId`为本站稳定ID。不同来源的同名游戏不自动合并；必须有发行方、原发布页或平台ID等证据才能建立跨平台映射。未知游戏使用来源命名空间ID，不借用已整理游戏的素材。

每份榜单必须包含`sourceId`、`sourceUrl`、`boardId`、`platform`、`period=day`、`definitionVersion`、`sourceDate`、`observedAt`、`origin`、`verification`、`coverage`及真实`rows`。来源榜单日期与本站采集时间分别记录，页面构建时间不当作数据更新时间。历史导入须标记`reviewed_historical_import`，不能冒称本站当日抓取。

来源公开榜位范围用`coverage.limit`及说明保存，`complete`仅指该公开范围是否完整读取，不代表覆盖整个市场。榜位不转换成收入、用户数、广告消耗或活跃度。来源提供的估算与官方值需要不同字段和证据；本阶段不收录这类数值。

## 7/30/90日计算

- 以北京时间的来源日期筛选窗口；按来源＋榜单分别计算，不拼接不同机构榜位。
- 同日多次修订全部归档，展示时选该日最后一份已核验记录，不当成多个观察日。
- 昨日缺测、公开范围不完整、范围变化或统计口径版本变化时，不判断“新进榜”和涨跌。缺测日不补值、不按零排名处理。
- “新进榜”仅指相邻有效日、相同公开范围内新增；不代表首次发行或全市场首次上榜。
- 排名变化为`previousRank-currentRank`，正数表示上升；没有可比基线为`null`。
- 连续上榜按连续日历日期与实际出现计算，缺测中断；至少3个有效日才进入“连续上榜”统计。
- 一份快照只展示当日榜位，不画虚构曲线。没有数据时保留未知，不写“涨跌为0”。

## 广告、画像与预测

公开广告记录包含游戏、平台、素材链接、形式、开场钩子、玩法、美术风格、目标用户判断、观察日期、来源和核验状态。只有明确的广告来源证据进入共享广告库；商店宣传和产品实录继续属于产品视觉档案。CTR、CPA、ROI、消耗及其猜测值不进入当前数据契约。

画像`kind=survey`须有样本量、样本范围、调查周期及原始来源；`kind=inference`须关联具体画面证据、置信度和验证方法。没有调查时年龄和性别为`null`。玩家反馈另列原文来源、日期和样本范围，不把少数反馈外推成总体。

每项未来方向保留时间跨度（3/6/12个月）、案例、依据、风险、置信度及可推翻条件。现有3项仅为视觉依据支持的研究假设，`marketSignal=unknown`。在榜单历史、跨平台、竞品、广告和需求序列不足时，不判定成熟玩法上升或竞争饱和。置信度是定性证据评级，不是成功概率。

## 运行与接入顺序

每日北京时间10:30（UTC 02:30）运行同一发布流程：解包并验证旧素材 → 记录来源状态 → 生成真实记录的差分 → 数据校验及统计测试 → 将JSON提交回仓库 → 构建新页面 → 发布。仅使用GitHub自带临时令牌，不配置广告或数据服务密钥。尚未启用采集器时，`lastAttemptAt=null`，只记录运行状态，不生成排名快照。

人工核验快照可运行`node scripts/import-ranking-snapshot.cjs <已核验JSON路径>`。校验不通过则不入库。相同快照幂等跳过，同日新版本以摘要后缀另存。`node scripts/validate-intelligence.cjs`校验关键约束，`node --test tests/analytics.test.mjs`验证缺测、范围变化、涨跌和连续天数规则。测试中的合成数据只在tests目录，不进入发布产物。

下一阶段逐个接入有柴、引力引擎、MomoRank的免费公开最新榜：先验证公开范围、日期和正确榜位，再启用单个适配器。若遇登录、付费、验证码、禁止自动访问或格式变动，保持明确的`blocked`／`failed`状态，保留旧快照和日期；不绕过访问限制。巨量创意及腾讯创意入口先核实无需广告账户可访问的范围，再人工核验归档。

参考：minigame-rank-daily的每日快照与差分组织方式。未复制其代码或历史数据，代码许可与数据转载许可须分别审查。MomoRank收费历史不接入，自建历史从首份真实观察起累计。

## 页面与回退

首页市场雷达；游戏资料库聚合素材和关联研究；竞品广告（吸量研究）、用户画像、未来预测为独立核心页面。旧的美术风格与特效介绍不再作为核心一级页面，相关截图与GIF集中到游戏详情。

构建采用覆盖层，不重传或改写原始素材包。旧入口保存为`archive.html`，方便核对与回退；主站不再重复导航到旧分类页。若校验或发布失败，不替换当前线上版本。回退时可恢复前一Git提交的发布流程和入口，历史JSON另行保留，不执行强制覆盖推送。
